# Лабораторная работа 5.4: Изучение простой сети

Выполнил: студент группы БИС-2-23 Азаматов Адис.

Цель работы: познакомиться с устройствами простой сети и с тем, как они взаимодействуют: добавить в топологию два ПК и назначить им адреса IPv4, проверить связь между узлами разных сетей, создать веб-страницу на сервере DEVASC и открыть её с ПК, изучить список доступа межсетевого экрана FIREWALL и проверить, как его изменение влияет на доступ к серверу.
